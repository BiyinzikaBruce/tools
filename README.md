## 🛠️ Free tools

Every tool runs 100% in your browser. Nothing you paste is uploaded anywhere.

| Tool | What it does |
|---|---|
| 🔑 [**JWT Decoder**](https://biyinzikabruce.github.io/tools/jwt-decoder/) | Decode a token's header and payload, see iat/nbf/exp in local time, check expiry |
| 🔐 [**Secret Generator**](https://biyinzikabruce.github.io/tools/secret-generator/) | Secure random secrets for `.env`: `BETTER_AUTH_SECRET`, `CRON_SECRET` and more, in Base64, hex or Base64URL |
| 🧩 [**JSON & Base64 Tools**](https://biyinzikabruce.github.io/tools/json-base64/) | Format, minify, sort keys and validate JSON. UTF-8 safe Base64 encode/decode |
| ⏰ [**Cron Explainer**](https://biyinzikabruce.github.io/tools/cron-explainer/) | Cron schedules in plain English with the next 5 run times in your local time |

```bash
cd tools
npx serve .
```
